## What to Search

Don't search only for `procedural world building`. Search adjacent visual fields.

| Area | Search Terms |
|---|---|
| **World / Landscape** | `stylized 3D landscape` · `architectural landscape` · `graphic landscape` · `3D landscape` · `terrain visualization` · `isometric landscape` · `axonometric landscape` · `architectural model landscape` · `topographic design` |
| **Maps / Cartography** | `3D map` · `stylized map` · `map design` · `fictional atlas` · `experimental cartography` · `terrain map` · `world map visualization` |
| **2D × 3D** | `2D 3D illustration` · `diagrammatic landscape` · `3D graphic design` · `architectural diagram` · `map interface` |
| **Life / Organisms** | `abstract organism` · `organism illustration` · `abstract creatures` · `alien flora` · `creature design` · `fictional ecosystem` · `speculative biology` · `collective behavior visualization` |
| **Architecture / Civilization** | `fictional architecture` · `speculative architecture` · `settlement design` · `architectural morphology` · `procedural settlement` · `urban pattern` · `vernacular architecture` · `landscape architecture diagram` |
| **Graphic Language** | `diagrammatic design` · `cartographic design` · `editorial information design` · `information design` · `data physicalization landscape` |
| **Systems / Behavior** | `emergent systems` · `generative ecosystem` · `agent based art` · `swarm behavior visualization` · `ecological network visualization` |

## What to Look For

| Lens | Look For |
|---|---|
| **Color** | palette, contrast, accents |
| **Form** | curves, geometry, silhouette |
| **Terrain** | topology, scale, abstraction |
| **Life** | organisms, vegetation, groups |
| **Architecture** | form, placement, settlement |
| **Graphic** | symbols, lines, labels |
| **Typography** | type, annotation, hierarchy |
| **Composition** | density, scale, negative space |
| **Motion** | movement, growth, traces |
| **Concept** | rules, relationships, systems |

A reference does not need to resemble the final world. It may be useful for only one of these qualities.

---

## Save → Analyze

For references worth keeping:

| Question | Purpose |
|---|---|
| **What catches me?** | Identify the specific quality I like |
| **What can I learn from it?** | Extract a principle rather than copying |
| **What would I change?** | Adapt the idea into my own world |

       ↓

The Style Guide comes later, once recurring preferences become actual design decisions.
